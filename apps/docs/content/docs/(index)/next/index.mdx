Prisma Next is the next foundation for Prisma ORM. If you are trying Prisma Next for the first time, start with `create-prisma@next`.

:::warning[Prisma Next is still in development]

Prisma Next is not ready for production yet. Prisma ORM 7 is still the recommended choice for production applications today.

:::

## Start here

Create a new Prisma Next app:

```npm title="Terminal"
npx create-prisma@next
```

Then follow the quickstart for the database you picked:

## Already have an app?

Already have an app and database? Use `prisma-next init` from your project root.

```npm title="Terminal"
npx prisma-next init
```

The existing-project guides walk through setup for the database your app already uses.
