Prisma Next is the next foundation for Prisma ORM. It is an early look at the next Prisma ORM workflow, with a TypeScript-first runtime, query APIs, migrations, extensions, and project setup.

Read [The Next Evolution of Prisma ORM](https://www.prisma.io/blog/the-next-evolution-of-prisma-orm) for the full story.
