Start with `create-prisma@next` if you want Prisma Next to create the app. Use `prisma-next init` if you already have an app and database.

## Start a new project

```npm
npx create-prisma@next
```

Choose the template and database in the prompts. Setup writes the starter contract, runtime files, `prisma-next.md`, Prisma Next skills, seed script, and package scripts for the first run.

## Add to an existing project

```npm
npx prisma-next init
```

Run this from your app root. Choose the database you already use, let Prisma Next add the project files and skills, then use the generated package scripts for the first contract, migration, seed, and query steps.

## After setup

- Use the generated app scripts for the first run.
- Open `prisma-next.md` or the installed Prisma Next skills when you want agent-ready guidance inside the project.
- Change the starter contract when you are ready to model your own data.
- Open [What is Prisma Next?](/next/what-is-prisma-next) when you want the concepts behind the setup.
